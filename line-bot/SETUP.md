# ติดตั้งบอทไลน์ ContentFlow — ทำตามลำดับนี้

บอทนี้ทำอะไร: ทีมพิมพ์/วางรีพอร์ตงานในกลุ่มไลน์ของทีมได้ 2 แบบ (ฟรีทั้งคู่ ไม่มีค่าใช้จ่าย):
**วางข้อความคั่น Tab** (ก๊อปจากชีต) หรือ **พิมพ์เองมีป้ายกำกับ** (พิมพ์ตรงบนมือถือได้เลย แถมแนบรูปได้ด้วย)
บอทจะแปลงข้อมูลแล้ว **ตอบสรุปกลับมาให้เช็คก่อนเสมอ** พิมพ์ "ยืนยัน" ถึงจะบันทึกเข้าแอป ContentFlow จริง
(ข้อมูลไปที่เดียวกับที่แอปใช้ — Supabase — ไม่ใช่ Google Sheet) — มีโหมดพิมพ์เล่าเป็นประโยคอิสระด้วย Claude ให้เพิ่มทีหลังได้
(ข้อ 11) แต่มีค่าใช้จ่าย ไม่บังคับ

ไม่ต้องเขียนโค้ดเป็น แค่ทำตามขั้นตอนนี้ทีละข้อ ใช้เวลาประมาณ 15-20 นาที

---

## ข้อ 1 — เปิด Messaging API ให้ OA ของทีม (มี OA อยู่แล้ว)

1. เข้า [manager.line.biz](https://manager.line.biz) ล็อกอินด้วยบัญชีที่ดูแล OA ของทีม
2. เลือก OA ของทีม → **การตั้งค่า (Settings) → Messaging API** → กด **เปิดใช้งาน Messaging API (Enable)**
   (ถ้าเปิดไว้อยู่แล้วข้ามข้อนี้ได้เลย)

## ข้อ 2 — ปิด Auto-reply / Greeting message ของ OA

ที่หน้า Messaging API เดียวกัน หรือใน **การตั้งค่าการตอบกลับ (Response settings)**:
- **ข้อความตอบกลับอัตโนมัติ (Auto-reply messages)** → ปิด
- **ข้อความทักทาย (Greeting messages)** → ปิดได้ถ้าไม่อยากให้ตอบซ้อนกับบอท

ไม่ปิดข้อนี้ = คนพิมพ์ในกลุ่มจะเห็นทั้งบอทเราตอบ และ LINE ตอบอัตโนมัติซ้อนกัน งง

## ข้อ 3 — เอา Channel access token + เปิด webhook

ที่ [developers.line.biz](https://developers.line.biz) → เข้า Provider/Channel ของ OA ทีม → แท็บ **Messaging API**:

- เลื่อนลงหา **Channel access token (long-lived)** → กด **Issue** (หรือถ้ามีอยู่แล้ว ก็ก๊อปอันเดิม)
  → เก็บค่านี้ไว้ ใช้ในข้อ 5
- เลื่อนลงหา **Use webhook** → เปิดสวิตช์ (ตอนนี้ยังใส่ URL ไม่ได้ ข้ามไปก่อน กลับมาทำข้อ 8)

## ข้อ 4 — เปิดโปรเจกต์ Apps Script

1. เข้า [script.google.com](https://script.google.com) → **โปรเจกต์ใหม่ (New project)**
2. ตั้งชื่อโปรเจกต์ เช่น "ContentFlow LINE Bot"
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้งให้หมด แล้ว **ก๊อปทั้งไฟล์ `Code.gs` ในโฟลเดอร์นี้ไปวางแทน**

## ข้อ 5 — ใส่ค่าที่ตั้ง (token, ลิงก์ Supabase)

1. ในไฟล์ `Code.gs` หาฟังก์ชัน `setupProperties` ด้านบนสุด
2. แก้บรรทัด `LINE_CHANNEL_ACCESS_TOKEN:` — เอาค่าที่ได้จากข้อ 3 มาวางแทนข้อความ placeholder
   (ค่า `SUPABASE_URL` / `SUPABASE_KEY` ใส่มาให้แล้ว ไม่ต้องแก้ — เป็นค่าเดียวกับที่แอป app.html ใช้อยู่)
3. ที่แถบด้านบนของ Apps Script เลือกฟังก์ชัน **`setupProperties`** จากดรอปดาวน์ (ข้าง Run/Debug)
4. กด **Run (▶)** → ครั้งแรกจะขึ้นเตือนขอสิทธิ์ → กด **Review permissions** → เลือกบัญชี Google
   → จะขึ้นเตือน "Google hasn't verified this app" (**เป็นเรื่องปกติ** เพราะเป็นสคริปต์ของเราเอง ไม่ใช่ของคนอื่น)
   → กด **Advanced** → **Go to ContentFlow LINE Bot (unsafe)** → **Allow**
5. เช็คว่าทำงานสำเร็จ: เมนู **View → Logs** ต้องเห็นข้อความ "ตั้งค่าเรียบร้อย"

## ข้อ 6 — Deploy เป็น Web App

1. มุมขวาบน กด **Deploy → New deployment**
2. คลิกไอคอนเฟือง ข้าง "Select type" → เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** `Me` (บัญชีของคุณ)
   - **Who has access:** `Anyone` ← สำคัญมาก ถ้าเลือกผิด LINE จะยิงเข้าไม่ถึง
4. กด **Deploy** → กด **Authorize access** ถ้าถามอีกรอบ
5. จะได้ **Web app URL** ที่ลงท้ายด้วย `/exec` → **ก๊อปเก็บไว้** ใช้ในข้อ 7

## ข้อ 7 — เอา URL ไปใส่ใน LINE Webhook

กลับไปที่ [developers.line.biz](https://developers.line.biz) → แท็บ Messaging API ของ OA ทีม:

1. ช่อง **Webhook URL** → วาง URL ที่ลงท้าย `/exec` จากข้อ 6 → กด **Update**
2. เช็คว่าสวิตช์ **Use webhook** เปิดอยู่ (ทำไว้แล้วในข้อ 3)

> ⚠️ **ปุ่ม "Verify" ข้าง Webhook URL ขึ้นแดงหรือ error = เป็นเรื่องปกติ ไม่ได้แปลว่าพัง**
> Apps Script ตอบกลับด้วย redirect ก่อนหนึ่งจังหวะ ปุ่ม Verify ของ LINE ไม่ตามให้
> แต่ตอนส่งข้อความจริง LINE จะตามและใช้งานได้ปกติ — **อย่าเชื่อปุ่ม Verify ให้ทดสอบด้วยการพิมพ์จริงในข้อ 8 แทน**

## ข้อ 8 — เพิ่ม OA เข้ากลุ่มไลน์ของทีม + ลงทะเบียนแต่ละคน

1. เพิ่ม OA (บัญชีบอท) เข้ากลุ่มไลน์ของทีมตามปกติ (เหมือนเชิญเพื่อนเข้ากลุ่ม)
2. ให้ **ทุกคนในทีม** พิมพ์คำว่า `ไอดีฉัน` ในกลุ่ม (หรือทักบอทส่วนตัวก็ได้)
   → บอทจะตอบกลับ LINE user ID ของคนนั้น (ยาวๆ ขึ้นต้นด้วย `U`)
3. แอดมิน (คนที่ตั้งค่าระบบ) เอา userId แต่ละคนไปใส่ใน `LINE_MEMBER_MAP` ในไฟล์ `Code.gs`
   (ในฟังก์ชัน `setupProperties`) ให้ตรงกับ **ชื่อสมาชิกในหน้า "ทีมงาน" ของแอป ContentFlow เป๊ะๆ** เช่น:
   ```
   LINE_MEMBER_MAP: '{"U1234567890abcdef...":"New","Uabcdef1234567890...":"Opor"}'
   ```
4. รันฟังก์ชัน `setupProperties` อีกครั้ง (เหมือนข้อ 5.3-5.4) เพื่ออัปเดตค่าใหม่
5. **ไม่ต้อง Deploy ใหม่** สำหรับการแก้ `LINE_MEMBER_MAP` — ค่านี้อ่านสดทุกครั้งที่มีคนพิมพ์

> ทำไมต้องมีขั้นนี้: ตอนพิมพ์รีพอร์ต ถ้าแต่ละแถวระบุชื่อคนเอง (เช่น "...นิว...สำเร็จ") บอทจับคู่ชื่อได้เลยไม่ต้องพึ่งขั้นนี้
> ขั้นนี้ใช้เป็น **ค่าสำรอง** เผื่อแถวไหนไม่ได้ระบุชื่อคน จะได้รู้ว่าเป็นงานของใครที่พิมพ์เอง

## ข้อ 9 — ทดสอบจริง

พิมพ์ในกลุ่มแบบใดแบบหนึ่งด้านล่างนี้:

**แบบคั่น Tab** (ก๊อปจากชีตมาวางเหมือนที่เคยทำ):
```
03/09/2026	พฤหัสบดี	
HADA	ทดสอบระบบไลน์บอท		https://drive.google.com/test		นิว	รอตรวจ
```

**แบบพิมพ์มีป้ายกำกับ** (พิมพ์เองบนมือถือได้เลย ไม่ต้องก๊อปจากไหน — ฟรี ไม่ใช้ Claude):
```
วันที่: 8/09/26
แบรนด์: HADA
งาน: ทดสอบระบบไลน์บอท
จำนวน: 1
สถานะ: เสร็จ
```

**ป้ายกำกับที่ใช้ได้ทั้งหมด** (มีแค่ "วันที่" ที่บังคับ ที่เหลือใส่หรือไม่ใส่ก็ได้):

| ป้าย | ใส่ยังไง | ถ้าไม่ใส่ |
|---|---|---|
| `วันที่:` | เช่น `8/09/26` | **บังคับใส่** |
| `แบรนด์:` | ชื่อแบรนด์ | ไม่ระบุแบรนด์ |
| `งาน:` (หรือ `รายละเอียด:`) | รายละเอียดสั้นๆ | เว้นว่าง |
| `ประเภท:` | ตัดคลิป / ลงคลิป / ถ่ายฟุตเทจ / ออกกอง / อีเว้นท์ / พากย์เสียง / เขียนสคริปต์ / อื่นๆ | ใช้ "ตัดคลิป" |
| `จำนวน:` | ตัวเลข | ใช้ 1 |
| `สถานะ:` | เสร็จ/กำลังทำ/รอตรวจ/ลงแล้ว ฯลฯ (พูดธรรมดาก็เข้าใจ) | ใช้ "ดำเนินการ" |
| `คน:` (หรือ `ผู้ทำ:`) | ชื่อคนทำงานนี้ | ใช้คนที่พิมพ์เอง |
| `ลิงก์:` (หรือ `ไดร์ฟ:`/`ไดรฟ์:`) | ลิงก์ไดรฟ์งาน | เว้นว่าง |

**ทำหลายงานในวันเดียวกัน** พิมพ์ต่อกันในข้อความเดียวได้เลย แค่**เว้นบรรทัดว่างคั่นระหว่างแต่ละงาน**:
```
วันที่: 8/09/26
แบรนด์: HADA
งาน: ตัดคลิปรีวิวสินค้าใหม่
จำนวน: 1
สถานะ: เสร็จ

วันที่: 8/09/26
แบรนด์: WinkWhite
ประเภท: ถ่ายฟุตเทจ
งาน: ถ่ายฟุตเทจสินค้าใหม่
จำนวน: 2
สถานะ: ดำเนินการ
```
บอทจะพาร์สทีเดียวเป็นหลายงาน ตอบสรุปเป็นรายการเลขลำดับให้เช็ค พิมพ์ "ยืนยัน" ครั้งเดียวบันทึกครบทุกงาน

อยากแนบรูปด้วยก็ทำได้ — **ส่งรูปเข้ากลุ่ม** (ก่อนหรือหลังพิมพ์ข้อความข้างบนก็ได้ ภายใน 10 นาที) บอทจะจำรูปไว้ให้แล้วแนบเข้ากับ
งานนี้อัตโนมัติตอนกด "ยืนยัน" — ใช้ได้กับแบบพิมพ์มีป้ายกำกับเท่านั้น (แบบคั่น Tab ไม่รองรับการแนบรูป) และ**เฉพาะตอนพิมพ์งานเดียว**
ในข้อความนั้น (ถ้าพิมพ์หลายงานพร้อมกัน บอทจะไม่รู้ว่ารูปนี้เป็นของงานไหน เลยไม่แนบให้อัตโนมัติ)

ทั้งสองแบบบอทควรตอบสรุปกลับมาภายในไม่กี่วินาที พร้อมบอกให้พิมพ์ "ยืนยัน" — ลองพิมพ์ "ยืนยัน" แล้วเปิดแอป ContentFlow
ดูที่หน้า "รายงานการทำงาน" ว่ามีงานนี้ขึ้นมาจริงไหม (แล้วลบทิ้งได้เลยเพราะเป็นแค่ข้อมูลทดสอบ)

**บอทเงียบไม่ตอบอะไรเลย?** เปิด Apps Script → เมนูซ้าย **Executions** เป็นที่แรก:
- ไม่มีแถวเลย = ข้อความจาก LINE ยังไม่ถึงสคริปต์ (เช็ค Webhook URL ในข้อ 7 อีกที)
- มีแถวขึ้น Failed = โค้ดพัง กดดูรายละเอียด error ในแถวนั้น
  (ถ้าเป็นตอนส่งรูปแล้ว error ขึ้น "Authorization required" → กลับไปทำข้อ 5.3-5.4 อีกรอบเพื่อขอสิทธิ์ Google Drive เพิ่ม
  ตัวโค้ดใหม่ใช้ Drive เก็บรูปชั่วคราวระหว่างรอยืนยัน จำเป็นต้องขอสิทธิ์นี้เพิ่มจากตอนติดตั้งครั้งแรก)

## ข้อ 10 — เปิดแจ้งเตือน "งานเสี่ยงไม่ทันเดดไลน์" รายวัน (ไม่บังคับ แต่แนะนำ)

ระบบจะเช็คหน้า "สั่งงาน" ในแอป (งานที่ยังไม่เสร็จ + เลยกำหนดส่ง หรือใกล้ถึงกำหนดส่งภายใน 3 วัน
หรือมี "งานย่อย" เช่น "จองคิวนักแสดง" ที่ยังไม่เสร็จและเลยวันครบกำหนดของมันเองไปแล้ว) แล้ว**ส่งเข้ากลุ่มไลน์อัตโนมัติทุกเช้า 9 โมง
เฉพาะตอนมีงานเสี่ยงจริงเท่านั้น** (ถ้าไม่มีอะไรน่าห่วง จะไม่ส่งอะไรเลย ไม่รบกวนกลุ่ม)

ตั้งค่าครั้งเดียว: กลับไปที่ Apps Script → เลือกฟังก์ชัน **`setupDailyTrigger`** จากดรอปดาวน์ Run → กด **Run (▶)**
(อนุญาตสิทธิ์เพิ่มถ้าถาม) → เช็คว่าสำเร็จที่เมนู **Triggers** (รูปนาฬิกาซ้ายมือ) ต้องเห็นแถว `checkAtRiskAndNotify`

> **ต้องมีคนพิมพ์อะไรในกลุ่มอย่างน้อย 1 ครั้งก่อน** (เช่นตอนทดสอบในข้อ 9) ระบบถึงจะจำ "กลุ่มไหน" ให้ส่งแจ้งเตือนเข้าไปได้
> ถ้ายังไม่มีใครพิมพ์อะไรในกลุ่มเลยหลังติดตั้งบอท ให้พิมพ์อะไรก็ได้ในกลุ่มสักครั้งก่อน

## ข้อ 11 — เปิด "พิมพ์เล่าเป็นประโยคได้เลย" ด้วย Claude (ไม่บังคับ — มีค่าใช้จ่ายจริง)

ปกติบอทต้องการข้อความคั่น Tab แบบตายตัว (ข้อ 9) ถ้าอยากให้พิมพ์เล่าเป็นประโยคธรรมดาได้เลย เช่น
**"บันทึก ตัดคลิป HADA 2 ชิ้น เสร็จแล้ว"** หรือ **"สั่งงาน ถ่ายอีเว้นท์เปิดตัว กำหนดส่ง 20 ก.ย. ให้แป้งทำ"**
ต้องต่อกับ Claude (Anthropic) เพิ่ม — ขั้นนี้ข้ามได้ถ้ายังไม่อยากเสียค่าใช้จ่าย บอทจะใช้งานได้ปกติแค่ต้องพิมพ์คั่น Tab เท่านั้น

**ค่าใช้จ่าย:** คิดตามจำนวนข้อความจริง ประมาณ **0.02-0.05 บาทต่อข้อความ** (ใช้โมเดล Claude Haiku ซึ่งถูกและเร็ว)
ทีม 5-8 คน พิมพ์คนละ 2-3 ครั้ง/วัน ตกเดือนละประมาณ **20-60 บาท** — ต้องผูกบัตรเครดิต/เดบิตกับบัญชี Anthropic เอง

ขั้นตอน:
1. เข้า [console.anthropic.com](https://console.anthropic.com) → สมัคร/ล็อกอิน → เติมเงินเข้าบัญชี (มีขั้นต่ำ)
2. เมนู **Get API Keys** → **Create Key** → ตั้งชื่อ เช่น "contentflow-line-bot" → ก๊อป key ที่ขึ้นต้นด้วย `sk-ant-`
3. กลับไปที่ Apps Script → ไฟล์ `Code.gs` → ฟังก์ชัน `setupProperties` → แก้บรรทัด `ANTHROPIC_API_KEY:`
   เอา key จากข้อ 2 มาวางแทน placeholder
4. เลือกฟังก์ชัน `setupProperties` จากดรอปดาวน์ Run → กด **Run (▶)** อีกครั้ง เพื่ออัปเดตค่า
5. ทดสอบ: พิมพ์ในกลุ่ม `บันทึก ตัดคลิป HADA 1 ชิ้น เสร็จแล้ว` → บอทควรตอบสรุปกลับมาให้เช็คเหมือนเดิม

**ไม่อยากเสียเงิน?** ข้ามข้อนี้ไปได้เลย ปล่อย `ANTHROPIC_API_KEY` เป็น placeholder เดิมไว้ — ถ้ามีคนพิมพ์ "บันทึก"/"สั่งงาน"
บอทจะตอบว่ายังไม่ได้ตั้งค่าฟีเจอร์นี้ แล้วแนะนำให้พิมพ์แบบคั่น Tab แทน ไม่กระทบการทำงานส่วนอื่นเลย

## ข้อ 12 — เปิดแจ้งเตือนเพิ่มเติม (ไม่บังคับ)

ตั้งค่าครั้งเดียว ทำแบบเดียวกับข้อ 10 (เลือกฟังก์ชันจากดรอปดาวน์ Run แล้วกด Run ▶):

| ฟังก์ชัน | แจ้งเตือนอะไร | ความถี่ |
|---|---|---|
| `setupMissingReportTrigger` | ใครยังไม่ส่งรีพอร์ตประจำวันของวันนั้น | ทุกวัน 19:00 น. |
| `setupUpdatesTrigger` | มีงานสั่งใหม่เข้ามา + มีคลิปที่เพิ่งเปลี่ยนสถานะเป็น "Post" (ลงจริงแล้ว) | ทุก 15 นาที |

ทั้งสองอย่างเช็คแล้ว**ไม่มีอะไรใหม่ก็จะไม่ส่งอะไรเลย** ไม่รบกวนกลุ่ม — และรอบแรกหลังติดตั้งจะ "จำของเดิมไว้เฉยๆ"
ไม่แจ้งย้อนหลังทั้งหมดที่มีอยู่ก่อนแล้ว (กันข้อความถล่มกลุ่มตอนเพิ่งติดตั้ง)

อยากเปลี่ยนเวลา/ความถี่ แก้ที่บรรทัด `.atHour(19)` หรือ `.everyMinutes(15)` ในฟังก์ชันนั้นๆ ใน `Code.gs` ก่อนกด Run

## หลังติดตั้งเสร็จแล้ว ทีมพิมพ์อะไรได้บ้าง

| พิมพ์ | บอททำอะไร |
|---|---|
| วางข้อความรีพอร์ตคั่น Tab (แบบเดิมที่เคยส่งกัน) | แปลงข้อมูล + ตอบสรุปกลับมาให้เช็ค (ฟรี) |
| แบบมีป้ายกำกับ เช่น `วันที่: 8/09/26` ตามด้วย `แบรนด์: ...` `งาน: ...` `จำนวน: ...` `สถานะ: ...` | พิมพ์เองบนมือถือได้เลย ไม่ต้องก๊อปจากชีต (ฟรี ไม่ใช้ Claude) — ส่งรูปแนบไปด้วยได้ (ก่อน/หลังก็ได้) |
| `บันทึก ...` เช่น "บันทึก ตัดคลิป HADA 1 ชิ้น เสร็จแล้ว" | พิมพ์เล่าเป็นประโยคอิสระ ให้ Claude ช่วยแยกเป็นรีพอร์ตงาน (ต้องตั้งค่าข้อ 11 ก่อน มีค่าใช้จ่ายเล็กน้อย) |
| `สั่งงาน ...` เช่น "สั่งงาน ถ่ายอีเว้นท์เปิดตัว กำหนดส่ง 20 ก.ย." | พิมพ์เล่าเป็นประโยค ให้ Claude ช่วยสร้าง "สั่งงาน" ใหม่ (ต้องตั้งค่าข้อ 11 ก่อน) |
| ส่งรูปเข้ากลุ่ม | บอทเก็บรูปไว้ชั่วคราว รอแนบกับรายงานที่พิมพ์ตามมา (เฉพาะแบบมีป้ายกำกับเท่านั้น — แบบคั่น Tab/บันทึก/สั่งงาน ไม่รองรับ) |
| `ยืนยัน` | บันทึกรายการล่าสุดที่เพิ่งแปลงเข้าระบบจริง (ไม่ว่าจะมาจากรูปแบบไหนด้านบน) |
| `ยกเลิก` | ทิ้งรายการที่ค้างไว้ ไม่บันทึก (รวมรูปที่ค้างไว้ด้วยถ้ามี) |
| `ไอดีฉัน` | บอก LINE user ID ของตัวเอง (ใช้ตอนลงทะเบียนครั้งแรก) |
| `เช็คงานเสี่ยง` | เช็คตอนนี้เลยว่ามีงานสั่งงาน (สั่งงาน/แคมเปญ) ที่เสี่ยงไม่ทันเดดไลน์ไหม (ตอบได้ทั้งกรณีมี/ไม่มี) |
| ข้อความอื่นๆ ที่ไม่เข้ารูปแบบไหนด้านบน (แชทเล่นปกติ) | **บอทเงียบ ไม่ตอบ** — ตั้งใจให้เป็นแบบนี้ กันบอทตอบก่อกวนแชทปกติของกลุ่ม และกันเรียก Claude โดยไม่ตั้งใจ (ประหยัดค่าใช้จ่าย) |

**นอกจากบอทจะตอบเมื่อมีคนพิมพ์แล้ว ยังส่งแจ้งเตือนเข้ากลุ่มเองอัตโนมัติได้ด้วย** (ถ้าตั้งค่าไว้ตามข้อ 10, 12):
งานเสี่ยงไม่ทันเดดไลน์ (ทุกเช้า 9 โมง), ใครยังไม่ส่งรีพอร์ตวันนี้ (ทุกเย็น 19:00), งานสั่งใหม่ + คลิปที่เพิ่งลงจริง (ทุก 15 นาที)

**เกี่ยวกับ "งานย่อย" ที่ทำให้เกิดการเตือน:** เพิ่ม/แก้ได้จากแอป ContentFlow เท่านั้น (หน้า "สั่งงาน" → เปิดงานที่ต้องการ →
ส่วน "งานย่อยที่ต้องทำก่อน") — บอทไลน์ไม่มีคำสั่งเพิ่มงานย่อยโดยตรง เพราะงานย่อยมักต้องระบุวันที่ครบกำหนดเฉพาะเจาะจง
กรอกในแอปแม่นยำกว่า

## ข้อจำกัดที่ควรรู้

- **งานพากย์เสียงรวมหลายคน/หลายคลิปในบรรทัดเดียว** และ **งานที่เป็นการแก้ไขงานเดิม** (ไม่ใช่งานใหม่)
  — บอทจะข้ามหรือบันทึกเป็นงานใหม่ไปก่อนแล้วแจ้งเตือน ให้เข้าไปจัดการในแอปแทน (เหมือนปุ่ม "วางข้อความจากไลน์" ในแอป)
- ถ้าจับคู่ชื่อแบรนด์/ชื่อคนไม่ได้ บอทจะบันทึกแบบไม่ระบุแบรนด์/เดาคนพิมพ์เองไปก่อน ต้องเข้าแอปไปแก้ทีหลัง
- รายการที่ค้างรอ "ยืนยัน" จะหมดอายุใน 10 นาที ถ้าเกินต้องพิมพ์รีพอร์ตส่งใหม่ (รูปที่ส่งไว้ก็หมดอายุพร้อมกัน)
- **แบบพิมพ์มีป้ายกำกับ**: ทำหลายงานในข้อความเดียวได้ (เว้นบรรทัดว่างคั่น) แต่รองรับเฉพาะรีพอร์ตงานประจำวันเท่านั้น
  (ยังไม่รองรับสร้าง "สั่งงาน" แบบนี้ — ใช้โหมด Claude ข้อ 11 หรือกรอกในแอปแทน) และแนบรูปอัตโนมัติได้เฉพาะตอนพิมพ์งานเดียว
- **รูปที่แนบ**: เก็บตามที่ LINE ส่งมาให้ (ไม่ได้ย่อขนาดเพิ่ม) ปกติไม่ใหญ่มากอยู่แล้วเพราะ LINE บีบอัดให้ก่อนส่งมา
- **โหมด "บันทึก"/"สั่งงาน" (พิมพ์เป็นประโยค)**: Claude เข้าใจภาษาพูดได้ดีแต่ไม่ได้แม่นยำ 100% เสมอ — ระบบยังคง
  **โชว์ตัวอย่างที่แปลงได้ให้เช็คก่อนเสมอ** เหมือนโหมดคั่น Tab ทุกประการ ไม่มีทางบันทึกเข้าระบบจริงจนกว่าจะพิมพ์ "ยืนยัน"
  ถ้าแปลงผิด พิมพ์ "ยกเลิก" แล้วลองพิมพ์ใหม่ให้ชัดเจนขึ้น หรือกรอกเองในแอปแทนได้เสมอ
- แก้โค้ดใน `Code.gs` แล้วต้อง **Deploy → Manage deployments → ✏️ (แก้ไข) → New version** ทุกครั้ง
  (แก้ไฟล์เฉยๆ ไม่พอ ต้องกด deploy เวอร์ชันใหม่ URL เดิมใช้ได้ต่อ ไม่ต้องกลับไปแก้ที่ LINE อีก)
